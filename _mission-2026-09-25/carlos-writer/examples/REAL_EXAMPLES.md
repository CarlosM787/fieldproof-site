# Real-example check: the exact prompts

Five passages of published copy from carlosmoralesjr.com (source: `carlosmoralesjr-site@fc65513`), run through each action. Generated by `scripts/build-examples.js` with the extension's own prompt builder (`extension/lib/prompts.js` v0.1.0), default settings, style guide: **Neutral default (shipped)**.

**No model was run here.** This container has no GPU and model downloads are blocked, so this file shows what would be sent, not what a model would answer. To see answers and timings on Carlos's PC, run `scripts/selftest.ps1` after installing Ollama and a model (his decision).

Every request goes to `POST http://localhost:11434/api/chat` with `"think": false`, `"options": {"num_ctx": 8192, "top_p": 0.9, "temperature": 0.1 | 0.2 | 0.4, "num_predict": ...}`. The extension streams (`"stream": true`); the self-test uses `"stream": false` to read Ollama's timing fields.

## The five passages

1. **home-lead** (Home page lead, https://carlosmoralesjr.com/)

   > I’m an electrical engineer. At night I build software under a studio name, Morales Labs. Then I write down what actually happened to it, with the numbers attached, including the ones that came back zero.

2. **about-night** (About page, second paragraph, https://carlosmoralesjr.com/about/)

   > At night I build software. For about a year that happened under a studio name, Morales Labs: a salsa timing trainer, an estimating app for contractors, spreadsheet systems for home bakers and pet sitters, a tool that reads store reviews and cites its sources, a finance copilot that has to show where every number came from. In September 2026 I finally shipped. Four products went live on Etsy and Gumroad. Nobody bought anything. I wrote about that too.

3. **salsacoach** (Projects page, SalsaCoach, https://carlosmoralesjr.com/projects/)

   > A timing trainer built around a real recorded salsa band instead of a click. You tap the 1 and it tells you, in milliseconds, whether you were early or late. On1 and On2, English and Spanish. The Android app is built and verified on a real phone. No dancer has used it yet. The free browser trainer works today.

4. **talkestimate** (Projects page, TalkEstimate, https://carlosmoralesjr.com/projects/)

   > A contractor walks the job and talks. TalkEstimate turns the walkthrough into an organized estimate. The AI organizes the scope; it never sets or changes a price. The Android build is finished. I’m doing my own phone check before the first contractors try it.

5. **subscribe-get** (Subscribe page, "What you’ll get", https://carlosmoralesjr.com/subscribe/)

   > Pieces that start from something that actually happened: shipping products nobody bought, a bug found at 1:43 in the morning, a 29-mile run. Building is the anchor, not the whole boat, so expect running, salsa, money and whatever I changed my mind about.
