Local model

How to set up the local model (about 10 minutes, one time)
  1. Install Ollama for Windows from ollama.com. It runs in the tray.
  2. Open PowerShell and run ollama pull llama3.1:8b (about 4.9 GB).
  3. Click Check connection above.

Carlos Writer talks to Ollama only at localhost:11434. You do not need to change OLLAMA_ORIGINS: the extension removes the browser Origin header from its own requests to that address, and from nothing else.

Anthropic API (optional)

Privacy and cost. When this is selected, the text you select is sent over the internet to Anthropic (api.anthropic.com) and billed to your API account: about 1 to 2 cents per 1,000 words with Claude Haiku 4.5 (estimate from $1 per million input tokens and $5 per million output tokens, price checked 2026-09-26). Your key is stored only in this browser profile's local extension storage. It is not synced, not shown to web pages, and never logged.

Privacy

  • Carlos Writer reads a page only when you use one of its shortcuts or its right-click menu, and then only the selected text. The toolbar button only sees what you paste into it.
  • The text goes to one place: the model selected above. With the local model, it stays on this computer.
  • It never reads password fields, one-time-code fields or card-number fields.
  • It changes the page only when you click Replace. Ctrl+Z undoes the change in most editors.
  • No analytics, no telemetry, no remote code. Settings stay in this browser profile.
